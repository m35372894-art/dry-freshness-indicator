# 🥦 DIY Bio-Based Freshness Indicator Sticker

An eco-friendly, low-cost smart packaging concept that detects meat and seafood spoilage in real-time without electronics.

---

## 💡 Overview

Food waste is a global challenge, often caused by conservative "Best Before" dates. This project demonstrates a passive chemical indicator using natural anthocyanins extracted from red cabbage. 

The sticker reacts to Total Volatile Basic Nitrogen (TVB-N) gases (such as ammonia and trimethylamine) released during protein decomposition, changing color from Violet (Fresh) to Bright Green (Spoiled).

---

## 🛠️ How It Works

1. Extraction: Anthocyanin pigment is extracted from red cabbage using ethanol or water.
2. Matrix Prep: Filter paper is impregnated with the solution and dried in the shade.
3. Assembly: A 3-layer sandwich structure isolates the indicator from external air while allowing food packaging gases to pass through.
4. Detection: As spoilage occurs (~18–24 hours at room temp), gases alter the pH environment, triggering a visual color shift.

---

## 📊 Key Features

- Zero Electronics: 100% passive, cost-effective, and biodegradable.
- Accessible Materials: Can be built using household items or simple lab supplies.
- Visual Feedback: Instant color shift readable by the human eye.
